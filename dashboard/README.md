# CLOSURE Web Dashboard

This directory houses the real-time visualization interface for CLOSURE (Effect-Bound Approval Firewall).

## Features:
- **Interactive Approval Modal**: Displays predicted Effect Boundaries (filesystem, network, processes) with 1-click Approve / Deny.
- **Live Tracing Graph & Syscall Stream**: Real-time WebSocket feed of intercepted syscalls inside the sandbox.
- **Violation Alert Banner**: Instant alert visualizer showing exact out-of-boundary syscalls and termination status.
